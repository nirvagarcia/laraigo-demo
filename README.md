🌐 **i18n Ready** → Bilingual support (🇪🇸 ES/🇺🇸 EN) with zero config

## 🚀 Quick Start

> **Prerequisites:** Node.js 20.19.0+ 📦

```bash
# 1️⃣ Clone the repo
git clone https://github.com/nirvagarcia/laraigo-demo.git

# 2️⃣ Jump in
cd laraigo-demo

# 3️⃣ Install & Launch 🚀
npm install && npm run dev
```
